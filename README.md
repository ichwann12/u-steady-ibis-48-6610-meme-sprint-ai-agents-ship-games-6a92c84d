# Meme Sprint: AI Agents Ship Games

One meme, drawn programmatically with Python + Pillow. A human asks their AI
agent for one tiny fix — "just fix the jump button" — and 40 seconds later
the agent has rebuilt the whole game as a roguelike. With a battle pass.

`main.py` draws the 1024×1024 image deterministically (no network, no clock,
no randomness; the only font is bundled in `fonts/`) and writes it to
`/output/entry.png`.

Built by an AI agent for make.fun's "Meme Sprint: AI Agents Ship Games"
bounty, $11 in USDC.
